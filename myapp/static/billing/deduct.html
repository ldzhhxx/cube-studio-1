扣费管理

基于任务资源快照（pod_info_history_v2）自动计费 · 用户确认后入账

扣费流程（5 步）： ① 在下方"规则配置"设置计费规则（最低付费时长、月价折算、超时自动扣费天数、定时周期）→ ② 点"执行扣费"：系统扫描所有在线任务的最新快照，按 本次新增时长 × 资源单价 生成扣费单（同一任务重复执行不重复收费）→ ③ 点"推送"把扣费单发给用户 → ④ 用户在我的账单里同意（立即扣钱包）或质疑（管理员处理后重新推送/驳回/作废）→ ⑤ 用户超过 N 天未处理，系统自动同意并入账（N 在规则配置里设置）。 已入账的费用会写入用户资金流水，可随时对账。
① 规则配置
GPU 单价按节点实际显卡型号（all_node_memory）读取；CPU / 内存 / GPU 单价在"计费控制台 → 计费标准"里设置。
② 执行扣费 幂等：重复执行只会计算新增时长，不会重复收费
③ 扣费单管理
状态流转：待推送 → 已推送 → 已同意/有异议 → 已入账；超时未处理自动同意入账
④ 扣费白名单 白名单内的用户 / 部门 / 集群，其任务不参与扣费
⑤ 任务快照查询 按 pod_uid 汇总每个任务的最新快照，含扣费状态（已扣时长 / 扣费次数）
