API 接入说明

以下接口供外部费用清单系统调用，鉴权统一使用请求头 X-Billing-Token（值在平台配置 BILLING_TOKEN 中设置）。

POST 推送费用明细（外部系统对接主接口，支持一次批量多条）

POST /billing/api/push Content-Type: application/json X-Billing-Token: <你的token> [ { "username": "zhangsan", # ab_user 中的用户名 "task_name": "train-resnet50", "pod_name": "resnet50-x7f2k", # 幂等键：重复推送只修正数据，不重复扣费 "cpu": 4, "memory": 16, # 资源数（核/GB） "gpu_num": 1, "gpu_memory": 16, # GPU 卡数 / 显存 GB "duration_seconds": 3600, "amount_fen": 1234, # 费用（分），金额以推送为准 "start_time": "2026-08-03 10:00:00", "end_time": "2026-08-03 11:00:00" } ]
返回 result 取值：settled 已入账扣费 / updated 重复推送已修正（金额变化自动差额补扣/退回）/ settled_no_user 用户名对不上未扣费 / skip 缺 pod_name / reject 金额非法（负数或超 100 万元）/ error 单条异常（不影响同批其他数据）。

POST 手动扣费（与页面同款：resources 后端自动算价，支持单个对象或数组批量）

POST /billing/api/deduct Content-Type: application/json X-Billing-Token: <你的token> # 或管理员会话 [ # 单条可传对象 {"username": ...} { "username": "zhangsan", "resources": [ # 资源明细，金额由后端按计费标准自动计算 { "item_key": "cpu", "quantity": 4 }, # 数量型：CPU 4 核 { "item_key": "GPU_l20", "quantity": 100 } # 子型号：L20 用 100G（item_key 在 /billing/api/prices 的 children 中） ], "duration_seconds": 7200, # 时长（秒），按月价折算 "task_name": "手动扣费任务", "remark": "扣费原因" } ]
金额由后端按计费标准权威计算（前端传不了假金额）；pod_name 不传自动生成 manual-用户名-时间戳；逐笔容错，返回 {count, ok, failed, results[]}。旧格式（cpu/memory/gpu_num/gpu_type 字段）仍兼容，自动转换为 resources。

GET 对账查询（外部核对平台入账状态）

GET /billing/api/list?username=zhangsan&pod_name=xxx&start_time=2026-08-01&end_time=2026-08-03&limit=200 X-Billing-Token: <你的token>

GET/POST 计费标准（登录用户可查，管理员可改）

GET /billing/api/prices # 所有登录用户，返回 items（含 children 子型号） POST /billing/api/admin/items # 管理员创建计费项 {"item_key":"storage","item_name":"存储","item_type":"quantity","unit":"元/GB/月","price_fen":50} POST /billing/api/admin/items/price # 改价 {"item_key":"GPU_l20","price_fen":7000} POST /billing/api/calc # 算价预览 {"resources":[{"item_key":"GPU_l20","quantity":100}],"duration_seconds":3600}
